3 · How to record

  1. Pick a save above, then GO (or a staged fight). Click the ARMED card, or press Space.
  2. Zoom is on: the MONITOR at the bottom shows the 9:16 take. Z tight or wide, F 16:9.
  3. The UI is OFF in the take. H puts it back in. D hand, C cursor, M sound, T voice-over.
  4. RECORD (R) asks where to save the take on this computer, then records what the monitor shows.
  5. STOP (R again) closes the file. It is done when the status line says saved.
  6. Takes live on your laptop, never on the big Mac. If QuickTime or Final Cut is picky: ffmpeg -i take.mp4 -c copy -movflags +faststart take-qt.mp4

4 · About this page

  • Takes live on your laptop, not on the big Mac. Desktop Chrome asks where to save each take (a file dialog at RECORD, written as it records). A phone or a browser without that dialog downloads the take at STOP instead (?dl=1 forces that road). A voice-over stem downloads beside the take.
  • Never play the real web game in this browser. This page and playgvt.net share one save; picking a seed above overwrites it. One save per browser: two armed tabs share it, but every armed link re-seeds itself on load.
  • HQ never hears of it: every call to the server is answered in this page's own bytes (the one read of the rankings board passes). The Director is a throwaway: no leaderboard rows, no rival rows, no telemetry, no ads.
  • Always the deployed build: this page is regenerated from the game's own bytes on every ship.
  • Off-camera law: place men outside the finder outline and let the battle walk into frame. Keep the window in front while recording (a hidden window stops drawing frames).
